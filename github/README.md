# 变更与 PR 历史记录

本目录的 `pr_*.md` 保存各次提交／PR当时的范围、验证和限制。文件名中的 current_branch 也指当时分支，不代表当前HEAD。历史测试结果不等于当前版本重新验证结果。

当前行为以代码和下列维护文档为准：

- [总体设计](../design/intercom-overview.md)：当前能力、架构及边界。
- [房间与控制台](../design/intercom-v2.md)：房间、动态用户、运行和联调。
- [协议](../design/intercom-protocol.md)：HTTP、WebSocket、AIR1与用户管理。
- [设备界面](../design/intercom-ui-480x320.md)：3.5B当前交互。
- [服务运行说明](../server/README.md)：依赖、启动、账户和存储。

2026-10-24按代码核对的主要差异：

- 控制台支持动态创建／查询用户和重置密码，所有用户权限相同；新数据库默认admin/admin123，已有数据库保留迁移后的密码。
- 登录Cookie为SameSite=Strict；退出撤销当前会话，重置任意用户密码撤销全部会话。
- 关闭正在发言的房间会中止音频并让成员回默认房间，当前不返回“发言中409”。
- 邀请不自动移动设备，空邀请列表表示开放加入；全局发言权尚未改为按房间独立。
- 浏览器已使用原始Opus；服务端立即转发，不以receive_ready作为首帧前置条件。
- 3.5B采用点击开始／再次点击结束；没有独立X按钮，右侧已支持临时记录与回放。

这些说明用于区分历史，不改写原PR所记录的实现与验证过程。
