## DHT11 温湿度监测

当前固件启动一个低优先级任务，上电等待至少 1 秒后读取 DHT11；每次读取结束
再等待至少 5 秒。成功通过 `DHT11` 日志标签输出温度（°C）和相对湿度（%RH），兼容整数及十分位数据，
失败打印错误并在下一周期重试；时序异常显示位序与脉宽，数据异常显示原始字节。无需联网，同时更新右侧“对讲记录”标题后的温湿度。
首次读取前显示占位符；偶发失败保留上次读数，15 秒未成功读取则显示“读取异常”，
恢复成功采样后自动显示数值。标签随中英文语言切换，固定在标题栏，不随记录滚动。

| DHT11 模块 | J8 PinOut |
| --- | --- |
| DATA / S | 第 11 脚，ESP_MOSI / GPIO10 |
| VCC / ＋ | 第 31 或 32 脚，3.3V |
| GND / － | 第 29 或 30 脚，GND |

GPIO10 与 SD 卡 MOSI 共用，使用此功能时必须取出 SD 卡，不可同时初始化 SD 卡。
模块应支持 3.3V；若无自带上拉，DATA 与 3.3V 之间接 4.7kΩ～10kΩ 电阻。
摄像头、屏幕和音频使用原有引脚。接线与时序依据 `docs/` 下的板卡原理图和
《DHT11 温湿度传感器变送器 探头》资料。

驱动使用 RMT 接收脉冲，不通过长时间关中断实现时序；传感器无响应或校验失败
不会中止固件。编译通过后仍需实机验证连续采样、传感器断开后重连，以及拍照、
对讲期间的采样稳定性。
